# 日ごとの学習記録

学習した日は、Codexが`YYYY-MM-DD.md`形式のファイルを作成または更新します。

例: `2026-08-17.md`

記録には、ロードマップ原文の項目、指定された操作、実際に実行したコマンド、状態、資料なしでできたこと、間違い、次回の実技問題を残します。説明の写しや長い教科書は置きません。

`ps aux`が指定されている日に`ps -p`だけを実行した場合のように、目的が近くてもコマンドが異なるときは別々に記録します。実行記録がない項目を推測で完了扱いにしません。

書式は[日次テンプレート](../templates/daily-log.md)を使います。
