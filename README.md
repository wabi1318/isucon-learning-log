# ISUCON学習ログ

ISUCONに向けた学習を、Codexと対話しながら進めるためのリポジトリです。

学習順、今日の時間配分、復習、次の課題はCodexが管理します。利用者は計画を覚えたり、毎回教材を探したりする必要はありません。

## 使うリポジトリ

この学習ログは、[Sakaguchi練習環境](https://github.com/topi-log/isucon2026-team-sakaguchi)と組み合わせて使います。標準では、二つを同じ親ディレクトリへ置きます。

```text
workspace/
├── isucon-learning-log/
└── isucon2026-team-sakaguchi/
```

別の場所に置いた場合、Codexがセッション内で場所を一度だけ確認します。個人環境の絶対パスは、このリポジトリへ保存しません。

練習環境の構成、参照ファイル、操作の安全区分は[practice-environment.md](practice-environment.md)にあります。

## 始め方

このリポジトリのルートでCodexを開始し、次の一言を送ります。

```text
今日やることを教えて
```

Codexはロードマップの日別項目を実行記録と照合し、期限が来た復習の後、今日以前で最も古い未完了項目から最初の5〜15分だけを案内します。結果を返すと、次の課題へ進みます。

初めてのテーマに教材がない場合は、同じセッションでPhase 0〜Phase 5の全体像が提示されます。内容を確認して`OK`と返すと、Phase 0の作成と学習が始まります。

## 練習環境との接続

教材は次の順で実環境へ近づきます。

1. 用語、構成、安全を確認する
2. 小さな基本操作を行う
3. 実際の設定やソースコードを読む
4. ComposeまたはLima VMで状態とログを観察する
5. 計測結果から原因を考える
6. 一変更一計測、または総合調査を行う

LinuxとsystemdはLima VM、短いコード、SQL、nginx実験はDocker Composeを基本にします。元ロードマップのMySQL前提は、[Sakaguchi練習環境への読み替え](roadmap/local-adaptation.md)に従ってPostgreSQLへ読み替えます。

## 1日の流れ

平日は60分を標準にします。

1. 5分: 前回の内容を資料なしで思い出す
2. 5分: 今日のゴールを確認し、最初に一度試す
3. 35分: 説明を読み、予想してから手を動かす
4. 10分: 資料を閉じ、もう一度操作または説明する
5. 5分: 間違いと次回の実技問題を記録する

Codexが「次は5分です」と一つずつ案内します。実際の時間を自動計測する機能ではないため、区切りでは結果または`完了`を返してください。

## 構成

```text
.
├── AGENTS.md             # Codexの学習コーチ運用
├── practice-environment.md # 練習環境と安全区分
├── study-status.md       # 現在地と次の一手の正本
├── roadmap/              # 全体計画、週別詳細、実環境への読み替え
├── hands-on/             # Phase 0〜5の教材
├── daily/                # 日ごとの学習記録
├── experiments/          # 計測と改善の記録
├── drills/               # 短い実技問題
├── reviews/              # 復習予定と結果
├── topics/               # 繰り返し使うテーマ別メモ
├── templates/            # 記録用テンプレート
└── prompts/              # 教材を作るときの手順
```

## 記録の約束

- ロードマップに明記された操作を一つずつ追跡し、似た別コマンドで完了扱いにしない
- 教材のPhase完了と、日別ロードマップの実行完了を別々に記録する
- 調べた文章をそのまま貼らず、自分の言葉で説明する
- 「読んだ」ではなく、資料なしでできた操作を記録する
- 分からないことを、次回の短い実技問題へ変える
- ベンチ結果は、仮説、条件、変更前後、採否、戻し方をセットで残す
- ファイルはリポジトリ相対パスで記録する
- 秘密情報、認証情報、個人情報、絶対パス、マシン名、生ログは書かない

学習ログの考え方は[参考リポジトリ](https://github.com/topi-log/isucon-learn/tree/main/daily-log)を参考にしています。学習計画は[ISUCON初参加チーム学習ロードマップ2026](https://github.com/topi-log/isucon2026-team-sakaguchi/blob/main/plans/isucon-learning-roadmap-2026.md)のローカルスナップショットを使います。
