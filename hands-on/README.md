# ハンズオン教材

テーマごとにPhase 0〜Phase 5の教材を置きます。

教材は`prompts/create-handson.md`に従い、学習で必要になったPhaseだけを作ります。未使用のPhaseを先回りして一括生成しません。

Phase 0〜1では前提と安全な基本操作を学びます。Phase 2以降は、Sakaguchi練習環境に実在する`task`、API、設定、ソースコードへ接続します。LinuxとsystemdはLima VM、短いコード、SQL、nginx実験はDocker Composeを基本にします。

教材には、練習リポジトリ内の相対パスだけを記録します。

最初のテーマは`linux-files-and-permissions/`を予定しています。「今日やることを教えて」と言うと、全体像の確認から始まります。
