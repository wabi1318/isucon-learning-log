# Linuxのファイルと権限

Linux上の設定、ログ、実行ファイルを安全に調べるための教材です。権限を暗記するのではなく、「誰が、何を、なぜ操作できるか」を説明できる状態を目指します。

## 全体の到達目標

- 絶対パスと相対パスを使い分けられる
- ファイル、ディレクトリ、シンボリックリンクを見分けられる
- 所有者、グループ、その他の利用者に対する`rwx`を読める
- 権限エラーを調べ、根拠のない`chmod 777`を避けられる
- Sakaguchi練習環境のservice利用者とファイル配置を対応付けられる

## 安全上の決まり

- Phase 0ではserviceや練習環境の状態を変更しない
- `.env`、認証情報、鍵、履歴を読まない
- `sudo`、`chmod`、`chown`は使わない
- 権限エラーを`chmod 777`で回避しない
- VMの起動や反映が必要になった場合は、影響と戻し方を確認してから行う
