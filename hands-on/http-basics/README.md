## 進め方

Phase 0から一つずつ進めます。Phase 1以降は、前のPhaseを完了した時点でまだ必要か再確認してから作ります。

Phase 0は2026-08-25に資料なしで完了しました。現在はPhase 1でブラウザの通信を観察します。

主要な操作は利用者が行います。実行前に何が起きるかを予想し、実行後に結果のどこを見て判断したか説明します。

## 安全上の決まり

- Phase 0ではコマンドを実行せず、状態を変更しない
- HTTPの観察ではロードマップに指定された公開先または練習環境だけを使う
- Cookie、Authorizationヘッダー、個人情報を表示・保存しない
- 長い通信結果は、必要な行だけを説明して記録する
- ログ追跡は8月20日の独立した項目として扱い、8月15日の完了へ混ぜない
