## 確認済みの構成

設定ファイルから、次の通信経路が想定されています。実際に待ち受けていることはPhase 1で確認します。

```text
Lima VMのnginx :80
  → Node.js :3000
  → src/server/index.ts
```

- `vm/nginx/sakaguchi.conf`: nginxが`80`で待ち受け、`/api/`を`127.0.0.1:3000`へ転送する
- `src/server/index.ts`: `PORT`が未指定の場合は`3000`でHono APIを起動する

補足として、この練習環境では`vm/lima.yaml`がホスト側の`:18080`をVM側の`:80`へ転送します。これは必須課題、完了条件、復習には含めません。

## 安全上の決まり

- Linux、systemd、プロセス、ポートの観察にはLima VMを使う
- `ss`、設定の読み取り、ログの読み取りは状態確認として扱う
- serviceの停止・再起動、`task vm:deploy`、設定変更は、この教材の8月19日部分では行わない
- `task vm:delete`やデータ削除は行わない
- プロセス一覧やログは必要な行だけを要約し、利用者名、マシン名、private IP、生ログを保存しない
- `127.0.0.1`は同じマシン自身を表す。この教材では公開用の接続先として使わない
